淘宝省钱卡转链工具

把普通淘宝搜索结果页的长链接转换为省钱卡搜索链接。

JavaScript 尚未运行。如果此提示一直存在，请用真正的网页浏览器打开，不要使用文件预览。
打开淘宝

使用方法

  1. 在普通淘宝搜索框输入商品名称。
  2. 分享搜索结果页，复制完整长链接（不是商品详情链接或淘口令短链接）。
  3. 粘贴到上方，必要时点击转换链接，再点击打开淘宝；如未跳转，复制新链接到浏览器打开。
  4. 确认进入省钱卡搜索页，并在结算时检查红包是否可用。
转换原理与隐私

删除 g_mainChannel、mainChannel 及已有的渠道、广告参数，添加 g_channelSrp=shengqianka_gmv_open 与 g_searchAdRate=0。其余原始参数保持不变。

本网页无外部脚本、无统计追踪、不保存输入、不向第三方发送链接。点击打开时才访问淘宝。转换结果仍保留输入链接自身的分享及会话参数，不建议将它公开发布。工具未内置任何用户的链接或账户标识。

非淘宝官方工具；能否搜索、跳转及使用优惠取决于淘宝客户端、账户及活动规则，可能随版本更新失效。
